- Problem (confirmed): With one model for everything, simple work runs on an expensive model, private work has no private model to go to, and no type of work can go to the group of models and thinking levels you'd pick for it. Getting any of that means switching models by hand.
- Occasion (confirmed): You have an agent or application that needs model routing.
- Incumbent (confirmed): You use Claude Code out of the box, with one expensive model for everything.
- Value (confirmed): You offload each type of work to a model whose cost, privacy and thinking level suit it, instead of putting everything through an expensive Claude. Agents and applications get that routing from one place, picked automatically from your preferences.
- Non-goals (confirmed): If you already have a routing solution, you don't need this. It picks a model and fallbacks for a job but doesn't run the job; hcn does that.
